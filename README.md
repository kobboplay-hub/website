# website

Kobbo — premium toy ecommerce storefront (Next.js + Shopify Headless).

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Shopify Storefront API

## Setup

```bash
npm install
cp .env.local.example .env.local
# Add SHOPIFY_STORE_DOMAIN and SHOPIFY_STOREFRONT_PRIVATE_TOKEN
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server
